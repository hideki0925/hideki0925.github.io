Privacy Policy

Last updated: 2026-10-12

Zero Second Brain is a personal tool used only by its owner. It is not offered to the public.

Data it accesses

  • Google Calendar: reads events and free/busy times; creates and edits only its own study-block events.
  • Gmail: reads messages and creates drafts. It never sends email.
  • YouTube: reads the owner's playlists (read-only).

How data is used and stored

Data is used only to help the owner plan study time and keep personal notes. It is stored only on the owner's own computer. It is not sold, shared with third parties, or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
